{{% alert title="Directorios adicionales bajo /" %}}

- `/opt` — Software adicional opcional.
- `/sys` — Información del kernel y hardware (sysfs).
- `/srv` — Datos para servicios del sistema.
- `/tmp` — Archivos temporales.
- `/usr` — Binarios, bibliotecas y documentación de usuario.
{{% /alert %}}
