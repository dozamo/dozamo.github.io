{{% alert title="/etc" %}}
`/etc` contiene archivos de configuración del sistema y de servicios.
{{% /alert %}}

## Ejemplos

- `/etc/passwd` — Información de cuentas de usuario.
- `/etc/fstab` — Configuración de montaje.
- `/etc/ssh/sshd_config` — Configuración de SSH.
