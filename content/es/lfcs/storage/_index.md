Este dominio profundiza en el núcleo de la gestión de datos en un sistema Linux, abarcando desde los dispositivos de bloque en bruto hasta el acceso a archivos en red. Un enfoque principal es la Gestión de Volúmenes Lógicos (LVM, por sus siglas en inglés), una capa potente y flexible que permite gestionar discos físicos como un único y dinámico grupo de almacenamiento, facilitando el redimensionamiento y la administración de volúmenes.

Obtendrá experiencia práctica en todo el ciclo de vida de los sistemas de archivos: crear, formatear, montar y solucionar problemas de sistemas de archivos comunes de Linux como ext4 y xfs. La sección explora cómo el Sistema de Archivos Virtual (VFS, por sus siglas en inglés) proporciona una interfaz unificada para estas diferentes tecnologías. Partiendo de esta base, aprenderá a ampliar el alcance de su servidor montando y utilizando sistemas de archivos remotos (como NFS) y dispositivos de bloque de red.

Finalmente, este dominio cubre tareas críticas de almacenamiento a nivel de sistema, incluyendo la configuración y gestión adecuadas del espacio de intercambio (swap) para complementar la memoria física, la configuración de automontadores de sistemas de archivos para el acceso bajo demanda, y el uso de herramientas para monitorizar la E/S (Entrada/Salida) y el rendimiento del almacenamiento para identificar y resolver proactivamente los cuellos de botella.
