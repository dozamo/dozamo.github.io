El directorio `/boot` contiene los archivos necesarios para iniciar el sistema

En este directorio se encuentran los archivos:
- Kernel (`vmlinuz`)
- Imágenes initramfs
- Archivos de GRUB

**Ejemplo:**
```bash
ls /boot
```
